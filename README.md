# Student Database Management System – MySQL

## About the Project
A SQL-based Student Database Management System developed using MySQL to store, manage, retrieve and analyse student academic records and technical skills.

## Database
- Database Name: student_db
- students table
- technical_skills table

## Features
- Student data storage and management.
- Calculation of average marks.
- Performance classification using SQL CASE statements.
- Identification of stronger subjects.
- Searching students by ID, email and course.
- Merit list generation.
- Identification of common technical skills.
- Filtering students based on subject scores.
- Data validation using constraints such as PRIMARY KEY, UNIQUE and CHECK.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## How to Run
1. Open MySQL Workbench.
2. Open the `student_database.sql` script.
3. Execute the script to create the database, tables, insert data and run queries.
