# Student Management REST API – Spring Boot & JDBC MySQL

## About the Project
A REST API developed using Spring Boot and JDBC to manage student records stored in a MySQL database.

## Features
- Connects a Spring Boot application to MySQL using JDBC.
- Performs student record management operations.
- Supports REST API requests.
- Uses a Model and Controller structure.
- Stores and retrieves student data from the database.

## Technologies Used
- Java
- Spring Boot
- JDBC
- MySQL
- Maven
- Postman

## Project Structure
- Model – Represents student data.
- Controller – Handles REST API requests.
- Database – MySQL database for storing student records.

## API Testing
The REST API endpoints can be tested using Postman.

## How to Run
1. Configure the MySQL database.
2. Update the database credentials in the application configuration file.
3. Run the Spring Boot application.
4. Test the API endpoints using Postman.
